# Emoji atlases

Generated by `scripts/build-atlases.ts` (`bun run generate`); do not edit by hand.

## Source

The artwork is **Apple's** emoji set, the one Telegram Web (tweb) ships: the 64×64 PNGs of
[iamcal/emoji-data](https://github.com/iamcal/emoji-data) `img-apple-64`, named by unified
codepoints. tweb keeps them with `-fe0f` stripped from the names (its `EMOJI.md`); the build
accepts either naming. The images are © Apple Inc.; the project owner accepted using them, as
Telegram does.

The emoji list comes from `emojibase-data` 17 (`en/data.json`). An emoji is listed only when the
art has it: at the time of writing that leaves out eight Emoji 17.0 additions Apple has not drawn
in this set (distorted face, fight cloud, hairy creature, ballet dancer, orca, landslide, trombone,
treasure chest), the skin tones of people with bunny ears and people wrestling, and the bare
♀ ♂ ⚕ signs. Text holding one of them keeps the system font.

## Layout

- `smileys`, `people`, `animals`, `food`, `travel`, `activities`, `objects`, `symbols`, `flags`:
  one atlas per category, default skin tone (components such as 🏽 sit in `people`).
- `tone1` … `tone5`: skin-tone variants by their first tone.
- Each sprite is a 68 px cell holding the 64 px art with 2 px of transparent margin, so a sprite
  drawn at a fractional scale never filters in its neighbour. `spriteSize` in the manifest is the
  cell.
- Manifest keys are the unified hexcode without `fe0f` (`unifiedHexcode()`).

## Rebuilding

```
# PNGs of img-apple-64 in scripts/.cache/apple-64 (gitignored), or pass --apple <dir>
bun run scripts/build-atlases.ts [--apple <dir>] [--quality 85]
```

It rewrites the atlases here, `index.json`, `src/data/emoji-data.json` (+ `.pretty.json`) and
`src/data/atlases.ts`. `test/atlasIntegrity.test.ts` checks that they agree.
